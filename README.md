# ÓRION CLINIC — Educação / Cursos

Atualização da área de formação profissional.

## Fluxo dos cards

Na página `cursos.html`, os cards de **Mentorias**, **Residência HOF** e **Workshops** agora funcionam em 3D:

1. clique/toque no card;
2. o card vira;
3. o verso mostra informações resumidas;
4. o botão **Ver página completa** abre a página individual do programa.

## Páginas individuais

- `mentorias.html`
- `residencia-hof.html`
- `workshops.html`

Cada página possui hero com imagem, apresentação detalhada baseada no conteúdo fornecido pela equipe, seções de proposta/experiência, FAQ, CTA para WhatsApp e navegação de volta para a formação.

## Observação de conteúdo

Não foram inventados valores, datas, duração, quantidade de vagas ou condições de inscrição. Quando esses dados não foram fornecidos, a página orienta o visitante a confirmar diretamente com a equipe da Órion.
